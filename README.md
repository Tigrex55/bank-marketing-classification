# Clasificación Supervisada: Bank Marketing (UCI)

Proyecto final de Ciencia de Datos enfocado en predecir la contratación de depósitos a plazo fijo mediante modelos de clasificación supervisada: Regresión Logística (referencia), Naive Bayes, SVM (lineal y RBF) y Red Neuronal Multicapa (MLP).
